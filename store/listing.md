# 스토어 제출 자료

크롬 웹 스토어와 웨일 스토어 등록 양식에 그대로 옮겨 쓰는 문구다. 제출 파일은 태그 릴리스가 만드는 `ma-chiara-<버전>.zip`이다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 이름 | 마! 치아라 — 광고 제거기 |
| 카테고리 | 크롬 웹 스토어 양식의 목록에서 "개인정보·보안(Privacy & Security)" 계열을 고른다 |
| 언어 | 한국어 |
| 개인정보 처리방침 URL | https://github.com/siyul-jh/ma-chiara/blob/main/PRIVACY.md |
| 지원 URL | https://github.com/siyul-jh/ma-chiara/issues |

## 요약 (132자 이내)

한국 사이트에 맞춘 광고 차단기. 네이버·다음·커뮤니티·언론사 광고를 막고 스크롤 잠금과 우클릭·복사 금지를 풀어 줍니다.

## 상세 설명

마! 치아라는 한국 웹을 기준으로 만든 광고 차단 확장 프로그램입니다.

■ 한국 사이트 우선
한국어 사이트 전용 필터 List-KR을 기본 규칙 맨 앞에 넣었습니다. 다른 확장 프로그램이 브라우저의 규칙 여유분을 다 써도 한국 사이트 차단은 유지됩니다.

■ 광고·트래커 차단
List-KR, EasyList, EasyPrivacy 규칙 10만여 개로 광고 요청과 트래커를 막고, 남은 광고 자리는 화면에서 숨깁니다.

■ 스크롤 잠금 해제
광고나 팝업이 남긴 스크롤 잠금을 자동으로 풉니다.

■ 우클릭·복사 금지 해제 (사이트별)
막혀 있는 우클릭, 텍스트 선택, 복사를 풀고 복사할 때 붙는 출처 문구도 막습니다. 웹앱을 깨지 않도록 필요한 사이트에서만 켭니다.

■ 요소 직접 제거
단축키(Alt+Shift+X)로 거슬리는 요소를 골라 지우면 다음 방문에도 계속 적용됩니다.

■ 사이트별 관리
사이트마다 차단을 끄거나, 특정 규칙만 해제할 수 있습니다. naver*.com 같은 와일드카드 도메인도 지원합니다.

개인정보를 수집하지 않습니다. 설정은 모두 기기 안에만 저장되며, 외부 요청은 하루 한 번 필터 목록을 받는 것뿐입니다.
소스 코드: https://github.com/siyul-jh/ma-chiara (GPL-3.0)

## 단일 목적 (Single purpose)

웹 페이지의 광고·트래커를 차단하고 광고로 인한 사용 방해(스크롤 잠금, 우클릭·복사 금지)를 없앤다.

## 권한 사용 이유 (Permission justification)

| 권한 | 입력할 문구 |
|---|---|
| declarativeNetRequest | 광고·트래커 네트워크 요청을 필터 규칙으로 차단합니다. |
| storage | 사이트별 설정과 사용자가 직접 제거한 요소를 기기 안에 저장합니다. |
| activeTab | 사용자가 팝업을 연 현재 탭에서만, 차단된 규칙 목록을 확인하고(사이트별 규칙 해제용) 요소 선택기를 실행합니다. |
| scripting | 요소 선택기 스크립트가 없는 탭(확장 설치 전에 열린 탭 등)에 선택기를 다시 넣습니다. |
| alarms | 광고 요소 숨김 규칙을 하루 한 번 갱신합니다. |
| 호스트 권한 (<all_urls>) | 사용자가 방문하는 모든 사이트에서 광고 요소를 숨기고 스크롤 잠금을 풀기 위해 콘텐츠 스크립트를 실행합니다. 페이지 내용은 수집하거나 전송하지 않습니다. |
| 원격 코드 사용 | 사용하지 않습니다. 하루 한 번 받는 필터 목록은 실행 코드가 아닌 텍스트 데이터이며, 번들된 파서가 기기 안에서 해석합니다. |

## 데이터 사용 공개 (Data usage)

- 수집하는 사용자 데이터: **없음** (모든 항목 체크 해제)
- 인증 항목: 판매하지 않음 / 핵심 기능과 무관한 용도로 쓰지 않음 / 신용도 판단에 쓰지 않음 — 세 항목 모두 체크
